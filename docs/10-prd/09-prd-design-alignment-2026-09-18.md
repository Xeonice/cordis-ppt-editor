# 09 PRD 与设计稿一致性：rulings §4.10 Q11–Q21 的现行结论

> 本文给出 rulings §4.10 Q11–Q21 各题的现行结论与归属文档，并列出相关的落点与未尽事项的现状；结论是摘要，以归属文档为准。

## 0. 结论

- Q11–Q21 都已落进 PRD 与设计，各题的现行结论与归属见 §2。
- 各题按哪条裁决执行：Q13、Q17 按 rulings §4.10；Q11 按 rulings §4.20 FE-05，删除被引用的版式确认后可撤销；Q19 的断点 1024 / 640 按 §4.10，紧凑与仅查看两种形态按 §4.25 DS-17；Q12、Q14、Q15、Q16、Q18、Q20、Q21 的入口与画法按 rulings §4.25。
- §4 逐项写未尽事项的现状：已定的写明落点，不再适用或不跟进的写明原因；`prefers-contrast: more` 现行设计与 NFR 未设。

## 1. 核对方法

PRD 与设计的一致性由下列检查维持，细则见 80-process/01、02、03。

| 检查 | 查什么 | 规则 | 工具 |
|---|---|---|---|

## 2. 各题的现行结论（rulings §4.10）

界面细节以同一行「归属」列里的设计为准。

| # | 议题 | 现行结论 | 归属 | 依据 |
|---|---|---|---|---|
| Q11 | 删除被引用的版式 | 引用数 > 0 时先弹确认对话框「删除版式「〈版式名〉」？」，写明仍被 N 个页面使用（第 x 页）、删除后这些页面改用默认版式、占位符里的内容会保留、删除后可以撤销；确认后受影响页改用默认版式（`defaultLayoutOf`），占位符按 ML-02 的规则重新匹配，一个事务，入撤销栈并给带「撤销」的轻提示，有无法匹配的元素时用 Q13 那一条。引用数为 0 时直接删除，给可撤销的轻提示。多选批量删除合并判定、只确认一次；删除被引用的母版同一形态。确认与撤销两层都有，是删除类操作确认策略的显式例外 | ML-03；PRD 07 G-73、D9；设计 03-26 §8 | rulings §4.20 FE-05 |
| Q12 | 母版视图在评审模式与窄屏下 | 只在编辑模式（有 `doc.write`）、桌面完整形态（视口 ≥ 1024、不是触控设备）、版本历史没开着且文档已打开时能进入。不能进入时，主菜单、命令面板与检查器上的入口留在原位、不可用并写原因：评审模式「评审模式下不可用」，查看者「只有查看权限」，编辑模式已降权「需要编辑权限」，紧凑窗口（640–1024）「在更大窗口中编辑」，版本历史开着「关闭版本历史后可用」，文档打开中「文档打开后可用」；按 `Mod+Alt+M` 不切换，给一次轻提示「母版视图：〈原因〉」。仅查看形态（< 640 或触控）没有主菜单与检查器，外接键盘按 `Mod+Alt+M` 时只给轻提示：宽度 < 640 写「在更大窗口中编辑」，平板写「在电脑上编辑」。嵌入里「在更大窗口中编辑」一律改写为「当前区域太窄，暂不可用」。放映中不响应。已在母版视图中时：缩到 640–1024 不退出，窗格与检查器收成抽屉；缩到 < 640 即退出；被降权时原地只读；手动切到评审即退出 | ML-01；PRD 07 D26；设计 03-26 §1.1 | rulings §4.25 TB-44、DS-162、DS-164 |
| Q13 | 换版式后元素无法匹配占位符 | 匹配不到的形状脱离占位符、保留为普通形状，给一条警告档轻提示「N 个元素无法匹配新版式的占位符，已保留为普通形状 [撤销]」；版式画廊、缩略图右键与幻灯片管理三处统一为这一条；点「撤销」一步回到原版式，跨母版时也回到原母版 | ML-02；设计 03-27 §4.1 | rulings §4.10 Q13 |
| Q14 | 编辑器的账户入口 | 编辑器右上角自己的头像（单页在检查器顶行，网格视图在右上胶囊）打开账户菜单，与开始页、文档列表是同一份条目（`UserMenu`）；在场头像与「分享」在检查器顶部协作行，网格视图与紧凑窗口在右上胶囊 | AS-06；设计 03-02 §6.2、03-29 §2.5 | rulings §4.25 DS-18 |
| Q15 | 切换效果的展示 | 不提供切换效果编辑：无选中时检查器「放映」节的「切换」是只读字段，显示文件里带来的切换效果（缺省「无」），留在原位、置灰，工具提示「切换效果已原样保留，M1–M3 暂不可编辑」；切换效果导出时原样保留 | ED-12；PRD 01 矩阵「切换效果」行；设计 03-02 §4.1 | rulings §4.10 Q15、§4.25 DS-21 |
| Q16 | 母版视图与版式的 8 项细节 | ① 不设「版式 \| 母版」编辑范围单选，窗格选中即编辑对象，对象名与继承来源写在母版视图横幅；② 版式画廊顶部有搜索框，按名称过滤全部分组；③ 选另一个母版下的版式时，所属母版与主题解析链一并切换，一个事务，撤销一步回到原版式与原母版；④ 母版数据超过 300 ms 未就绪才显示加载：横幅一句、窗格一行加载行、画布中央转圈，加载失败时画布整块状态加次按钮「重试」；⑤ 同一母版内多选版式可批量删除，规则同 Q11；⑥ 标题、页脚、日期、页码占位符每个版式各至多 1 个，「占位符 ▾」里对应项预先不可用并写「已包含」，竞态下仍超限时给轻提示；⑦ 影响页数写在横幅的说明段（「改动将影响 N 页」/「未保存改动 · 影响 N 页」）；⑧ 重置页为确认对话框加可撤销轻提示，是 D9 的显式例外 | ML-01、ML-02、ML-03；设计 03-26、03-27 | rulings §4.10 Q16、§4.25 DS-146、DS-154 |
| Q17 | 「设置为默认主题」「另存为新主题」 | 不提供这两项 | ML-04；设计 03-28 | rulings §4.10 Q17 |
| Q18 | 查看器的缩略图导航与备注 | 缩略图条与备注面板是查看器的可选能力：缺省关，由宿主选项开启，开启后按需加载，不计入 350 KB gzip 基线；文本搜索同为宿主选项。容器宽 < 640 时向编辑器仅查看形态靠齐：底部浮动翻页条，「更多」与缩略图为底部面板，备注为当前页下方的只读卡 | OF-14；设计 03-25 | rulings §4.10 Q18、§4.25 DS-111 |
| Q19 | 响应断点 | 断点为 1024 / 640：≥ 1024 为完整形态；640–1024 为紧凑形态，两侧面板收为左上、右上两个胶囊，按需展开为抽屉；< 640 或触控设备为仅查看形态 | EM-01、NF-07；设计 03-02 §5a | rulings §4.10 Q19、§4.25 DS-17 |
| Q20 | 文件与文档级命令的入口 | 分在主菜单与文档菜单：「文件 › 导出…」（`Mod+Shift+E`）与「文件 › 保真报告」（保真报告唯一的常驻入口）；主菜单顶层「插件…」打开个人插件面板（居中对话框）；文档菜单「重命名 · 创建副本 ┊ 版本历史」，评审者与查看者的文件名不是菜单触发器、没有这三项；保真报告与版本历史打开后是检查器整栏面板（沿用检查器宽度，缺省 280）；开发者面板在主菜单「帮助」最后一组，只在开发构建或部署打开开发者菜单开关时出现 | PRD 07 D27；设计 03-02 §2.3 | rulings §4.25 DS-18、DS-21 |
| Q21 | 控件边界的对比度 | 检查器控件用安静样式：数字与文本输入、下拉、分段与按下态靠底色、标签与当前值识别，边界不要求 ≥ 3:1；复选框、单选圈、插入表格网格与焦点环仍 ≥ 3:1 | NF-05「对比度」行；设计 04 §2.6 | rulings §4.25 DS-35 |

快捷键面板在编辑器里有三个入口：主菜单「帮助 › 键盘快捷键」、账户菜单「键盘快捷键」与 `Mod+/`，命令面板里的「键盘快捷键」同样打开它（ED-16、AS-06，设计 03-24 §2）。偏好设置的常驻入口只有账户菜单「偏好设置…」，`Mod+,` 与命令面板「偏好设置…」是第二入口（AS-06、PRD 07 D13，设计 03-23 §2）。

### 3.3 章程 / ADR / 架构

- 章程 D10 与 ADR-0017 决策 4：组件层复用 shadcn/ui；母版缩略图窗格（`MasterThumbnails`）是 `slide-ui` 的领域部件，`ui-react` 只提供槽位宿主（组件与文件见模块 40/10）。
- 章程 §5.2 `apps/web` 一行：参考应用含开始页、文档列表与账户菜单；账户菜单在开始页、文档列表与编辑器三处是同一个 `UserMenu`；编辑器主菜单与文档菜单里的应用级条目（导出、保真报告、插件、版本历史、重命名、创建副本）经宿主回调实现（Q14、Q20）。
- 删除被引用的版式与母版：默认版式按 `defaultLayoutOf` 取，删除母版时的目标母版与各页的版式取法见架构 30/04 §12 与 rulings §4.20 FE-03、FE-23（Q11）。

## 4. 未尽事项的现状

| 事项 | 现状 | 依据 |
|---|---|---|
| 暗色控件边界在强调色悬停面上的对比度 | 不再适用：控件用安静样式，边界不要求 ≥ 3:1；仍用控件边界色的拖动把手与画布的对比度 ≥ 3:1 | rulings §4.25 DS-35、DS-135 |
| 窄屏（< 640）与紧凑窗口（640–1024）的工具区 | 已定：紧凑窗口把两侧面板收为左上、右上两个胶囊，按需展开为抽屉；仅查看形态（< 640 或触控）为顶部条、当前页全宽、只读备注与底部翻页条，编辑类入口全部收起 | rulings §4.25 DS-17；设计 03-02 §5a |
| Sheet 圆角留白 | 不跟进：属旧版 playground 的实现，旧版在 v3 全量迁移完成后删除 | rulings §4.25 DS-7 |
| `contain: paint`、`data-interacting` | 不再适用：这两条是毛玻璃材质层的性能规则，随材质层作废；现行界面不用毛玻璃，同屏 `backdrop-filter` 为 0（NF-01 §1.8） | 设计 09 §6；rulings §4.25 DS-2 |
| `prefers-contrast: more` | 现行设计与 NFR 未设此项；高对比按 `forced-colors` 处理，M2 只出报告，M3 起为门禁 | NF-05「高对比模式」 |
| Esc 退出母版视图 | 已定：画布无选区时按 Esc 退出母版视图；Esc 每按一次只退一级，各级次序见设计 03-26 §1.1 | rulings §4.25 TB-195 |
| 删除被引用母版时各页改用的版式 | 已定：目标母版取按顺序排在首位的剩余母版，界面不加母版选择器；每个受影响页取目标母版下与原版式同类型的首个版式，没有则取目标母版的首个版式；整个删除一个事务，确认后可撤销 | rulings §4.20 FE-23；ML-03 |
