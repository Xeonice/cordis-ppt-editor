## 2. 跨路由共性问题（按出现次数）

## 3. 与 09 v3.0 的偏差

| 规则 | 路由 | 证据 |
|---|---|---|
| §3 画布覆盖层：10–12px 圆形手柄 | editor / insert / masters | 截图中为 6px 方块 |
| §2 检查器分区：分组卡三层 | layouts / text / insert | 裸文本行 |
| §2 空态：`Empty` 系列 | history | 裸文本 |
| §1.2 内容层不透明且用文档色 `doc-ink/paper` | insert 暗色 | 图片占位用了主题 `muted` 色，暗色下对比不足 |
| §5 审查清单：同一事件只用一层反馈 / 说明文字不进产品 UI | layouts 只读 | 状态栏中间出现 playground 说明 |

## 4. 值得保留的亮点

- 悬浮玻璃工具卡 + 侧栏卡 + 状态胶囊的层次，暗色下 rim 与高光让面板边缘清晰，不发灰。
- 画布上的协作语言（远端选区虚线框 + 名字胶囊、远端光标、评论钉）在亮暗两主题都一眼可辨。
- 母版视图：母版树 + "正在编辑"提示胶囊 + 继承占位符徽标，信息密度高但不乱。
- 版式选择器与重置确认对话框：Rhea 圆角、玻璃遮罩、默认焦点落在"取消"，符合可撤销优先。
- 版本历史的左列表 + 右预览 + 底部双按钮布局，恢复按钮在只读态正确禁用。

| 问题 | 处置 | 复核 |
