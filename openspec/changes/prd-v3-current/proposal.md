# Proposal

级别：L2
依赖：design-language-v3、dev-process

## Why

设计语言 v3 的第 0–3 批与母版视图改版都已评审通过（2026-11-05），但 PRD 在各批回写时只按批次原地修补：正文夹着约 260 处带日期的修订注记与「原…改读」，07 覆盖矩阵、08 / 09 对齐记录与 README §9 仍按旧设计或改读日志写，01 背景、02 用户场景从没按 v3 改过。新旧口径混在一起，后续实现与测试容易读错。用户 2026-11-05 要求基于定稿设计更新 PRD，直接改成最新版本，不保留修订记录。

## What Changes

- 核对改正：逐个功能域对照定稿设计（20-design 01–07、09，03-screens 01–33，v3 样张）与 rulings，改正 PRD 中不一致、过时与漏写的表述。PRD 复述的界面细节（文案、尺寸、位置、控件清单）保留，逐处改成与设计一致。需要新增需求，或改优先级、里程碑、范围的，逐题请用户裁决。
- 改为现行版：PRD 全部 18 份文件只写现行口径。删去带日期的修订注记、「原…改读」「已被…取代」与状态头里的更新历史，不另留修订记录（历史以 git 为准）。
- 07 覆盖矩阵按现行设计（界面规格与样张路由）重写，缺口 G-xx 写现行状态与落点；08、09 两份对齐记录逐条改写为现行结论与归属文档；README §9 由 v3 改读日志改为现行内容。
- 以下保持不变：需求编号、落点豁免、「已删除」标记、已有的缺口编号 G-xx（新缺口从 G-88 起编号）、章节编号（唯一例外是 NF-01 第二个 §1.5 改为 §1.8，PV-21）；需求块的优先级与目标里程碑除 PV-8、PV-10、PV-19 外不变。需求块与字段沿用 80-process/02 §1.1 的解析格式。
- 其他线：改引用了被删历史内容或已改节号、标题的地方，复述的 PRD 原文与功能名改为现行措辞（含后端引用的 SV 原文），设计线同样只改引用与措辞（界面与样张不变）；章程 §8 文档树按现行 PRD 改写 07、08、09 三行并补 `03-features/09-plugin-manager.md`，`20-design/03-screens/` 的范围改为 01–33；70/09 按 PV-20、PV-22 补 NF-01 §1.2 三项门禁的测量场景；`docs/_tools/terms.json` 删去只为 PRD 07 / 08 / 09 放行的旧名；G5 基线按棘轮收紧 1 处（G4 无可收紧）；rulings 新增 §4.26 记录本变更的用户裁决。

## 需求编号

修改（表述改为现行版，编号不变）：PRD 03 九个功能域与 PRD 04 的全部需求，逐条改动见 docs-sync 回写记录。其中按 rulings §4.26 改了范围或优先级的：

- 优先级：ED-30 由 P2 改为 P1（PV-10）；ED-09「显示文件里存的参考线」分项为 P1（PV-8）；PM-01、PM-05 的 M3 部分为 P1（PV-19）；SV-02、SV-03、SV-06、SV-07 写明分段优先级，P1 部分随 OF-19、PS-14、CO-07、CO-08、CO-15 与 rulings §4.12 U-15，取值不变（PV-26、PV-27）；ED-01 边界、ED-26 与 PRD 01 §2.4 的锁定对象呈现统一为 P1，锁定属性的查看与切换、选择窗格里的显隐切换为 P2（PV-28）。除 ED-30 由 P2 改为 P1 外，需求块的首个优先级与目标里程碑不变；G4 运行通过，没有新增缺口。
- 范围收窄：CO-03 删去查看者隐身（PV-11）；EM-06 间距与界面字号不开放覆盖（PV-13）；EM-08 不再整块隐藏左栏与检查器（PV-14）；SV-03、SV-05、SV-09 收窄到后端现状（PV-15）；SV-11 按后端已定做法（PV-17）；ML-03、ML-01 不编辑「其他」文本样式（PV-18）；ED-26 缺替代文本提示只对能在这里改替代文本的对象，表格提示待设计补（PV-31，PRD 07 G-38）。
- 范围补写：OF-14 查看器显示隐藏页（PV-4）；ED-03、ED-04、ED-07、ED-35 补五项 P2 能力（PV-7）；ED-28 M2 可切换连接符类型（PV-9）；CO-04、EM-02 导出评论的开关只在 SDK（PV-12）；NF-01 补三项时限门禁与 16.7 ms 帧时间门禁（PV-20、PV-22）；NF-05 适用范围与 200% 缩放的验收口径（PV-23、PV-24）；ED-05 补「插入后自动进入文本编辑」选项（P1，缺省关，PV-29）；NF-04 与 EM-14 的 SBOM 分两段：M1 起在 CI 中生成、属供应链门禁，随每次发布对外提供为 P1（PV-30）。
- 里程碑汇总：PRD 05、PRD 01 支持矩阵按需求块改（PV-26、PV-27），M0 文档范围列全各线（PV-25）；AS-06 的目标里程碑补写 M3 部分（「个人资料…」与平台管理员的「管理」，首个取值不变）。

新增：无。
